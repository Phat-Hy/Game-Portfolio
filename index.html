AI Balancing Service (2026)

Backend & live operations

Tuning enemy difficulty by hand does not survive real players. This is the service behind 81 Days and Nights: it collects what happened in each fight, scores every enemy configuration, and breeds the next generation of parameters — separately for every player.

Contributions

  • Genetic algorithm: four candidates per generation, elitist selection, 60/40 blending crossover, ±5% mutation
  • Fitness scored from combat telemetry, with mutation scaled by the player's death rate
  • REST API with JWT-secured admin endpoints and SHA-256 hashed credentials
  • Admin dashboard for live combat logs, generation tracking and manual overrides
  • CI/CD through GitHub Actions to Azure App Service

TrueEnding (2026)

Systems research & tooling

A byte-matching decompilation of The Last Story (Nintendo Wii), paired with a static recompilation that runs the game natively on PC instead of inside an emulator. Half the game's code is matched byte-for-byte, and the native runner draws it in a real window at a configurable frame rate.

Contributions

  • Build pipeline: a Python generator emitting Ninja + Metrowerks CodeWarrior builds, with per-unit byte-match reporting
  • Verification tooling: an interactive assembly diff helper and objdiff integration, plus a machine-readable progress ledger tracking match state per module
  • Native host runtime: memory mapping and MMIO shims so PowerPC 750CL guest code executes on x86-64 without emulator overhead
  • Matched low-level systems — OS threading and memory arenas, DVD/NAND I/O, GX graphics pipeline
  • Work spanning C, C++ and PowerPC assembly across 522 linked translation units

Solo — tooling, systems, native runtime

Local Avatar Engine (2026)

Hobby project — real-time 3D + local inference

An avatar that holds a conversation without touching the cloud: a local LLM runs on the GPU, a flow-matching speech model clones a voice, and both are lip-synced onto an MMD character rendered in the browser. No API keys, no telemetry, everything on one machine.

Contributions

  • Real-time pipeline: a WebSocket orchestrator streaming LLM tokens through sentence splitting, speech synthesis, viseme extraction and 3D lipsync, with instant speech interruption
  • Latency work: sub-second speech generation (real-time factor 0.09–0.14), GPU kernel warm-up to remove first-turn delay, 35–45 tokens/sec generation
  • 3D: MMD PMX and GLB avatars in Babylon.js, rigid-body secondary motion for hair and cloth, procedural breathing, blinks and eye saccades
  • Local inference: GGUF models via llama.cpp with GPU offload, plus swappable TTS backends behind one microservice
  • Streamed emotion and gesture tags parsed from text and mapped to facial blendshapes and bone animation
Role
Solo — engine, backend, front end
Stack
Python, FastAPI, PyTorch/CUDA, Babylon.js, llama.cpp
Runs
Fully offline on a consumer GPU

About
